# 04 · 主题系统与布局模式

## 1. 主题能力范围

| 维度                 | 支持        | 说明                                                     |
| -------------------- | ----------- | -------------------------------------------------------- |
| 明暗模式             | ✅          | `light` / `dark` / `auto`（跟随系统 `usePreferredDark`） |
| 品牌色               | ✅          | 预设色板 + 自定义取色器，运行时生成色阶覆盖 Element Plus |
| 圆角 / 尺寸 / 紧凑度 | ⛔ 本期不做 | 保留扩展位                                               |
| 灰阶 / 色弱          | ⛔ 本期不做 | 保留扩展位                                               |

> 布局偏好（侧边宽度、顶栏高度、动画、水印、全屏）属于**布局配置**，独立于主题，见 §5。

## 2. 令牌分层

```
┌ 设计令牌（Design Tokens）  app/styles/tokens/*.scss
│   --fsd-color-*  --fsd-radius-*  --fsd-space-*  --fsd-shadow-*
├ 语义变量（Semantic）       --el-color-*（Element Plus 变量在此被覆盖）
└ 组件样式                    scoped CSS，只消费变量
```

- 主题切换只改**令牌层**，组件不感知主题。
- Element Plus 的 `--el-color-primary*` 系列在运行时由 JS 写入（品牌色必须运行时计算，SCSS 变量做不到）。

## 3. 明暗模式

```ts
// features/theme-switch/lib/apply-theme.ts
const HTML = document.documentElement

export function applyDarkMode(mode: 'light' | 'dark' | 'auto') {
  const isDark =
    mode === 'dark' ||
    (mode === 'auto' && window.matchMedia('(prefers-color-scheme: dark)').matches)
  HTML.classList.toggle('dark', isDark)
  return isDark
}
```

- 全局引入 `element-plus/theme-chalk/dark/css-vars.css`（放在 `app/styles/element/` 中 `@use`/`@import`），配合 `html.dark` 生效。
- `auto` 模式下监听系统变化（`@vueuse/core` 的 `usePreferredDark`）。

## 4. 品牌色（核心难点）

Element Plus 主色依赖一组梯度变量：

```
--el-color-primary
--el-color-primary-light-3 / -5 / -7 / -8 / -9
--el-color-primary-dark-2
```

**方案**：在 `@repo/utils` 中实现色阶算法（零新增依赖），运行时写入 `documentElement.style`：

```ts
// packages/utils/src/color/shades.ts
export type ShadeKey = 'light-3' | 'light-5' | 'light-7' | 'light-8' | 'light-9' | 'dark-2'

/** 与 SCSS mix() 等价：weight 为 color1 的占比（0~1） */
export function mix(color1: string, color2: string, weight: number): string
export function generatePrimaryShades(primary: string): Record<ShadeKey, string>
```

> 签名以 `docs/10` §2.1 为准（已定型，不得改名）；不含 `DEFAULT`，基色由调用方直接透传。

实现要点：

- `light-N` = `mix('#ffffff', base, N / 10)`（如 `light-9` = 90% 白 + 10% base，最浅），`dark-2` = `mix('#000000', base, 0.2)`。
- 输入支持 `#RGB` / `#RRGGBB`，输出统一小写 `#RRGGBB`。
- 参考值（`primary = #409EFF`）：`light-3 #79bbff`、`light-5 #a0cfff`、`light-7 #c6e2ff`、`light-8 #d9ecff`、`light-9 #ecf5ff`、`dark-2 #337ecc`。
- **必须写单元测试**（`packages/utils` 单测覆盖重点）。

应用侧：

```ts
// features/theme-switch/lib/apply-theme.ts
export function applyPrimaryColor(hex: string) {
  const s = generatePrimaryShades(hex)
  const root = document.documentElement.style
  root.setProperty('--el-color-primary', hex) // 基色直接透传，无 DEFAULT
  root.setProperty('--el-color-primary-light-3', s['light-3'])
  root.setProperty('--el-color-primary-light-5', s['light-5'])
  root.setProperty('--el-color-primary-light-7', s['light-7'])
  root.setProperty('--el-color-primary-light-8', s['light-8'])
  root.setProperty('--el-color-primary-light-9', s['light-9'])
  root.setProperty('--el-color-primary-dark-2', s['dark-2'])
}
```

预设色板（放在 `features/theme-switch/model/constants.ts`）：

```
拂晓蓝 #409EFF（EP 默认）  极客蓝 #2F54EB  青翠 #13C2C2  明青 #36CFC9
日暮 #FAAD14  酱紫 #722ED1  薄暮 #F5222D  极光绿 #52C41A
+ 自定义（`FsdColorPicker`，由 `@repo/ui` 封装 `ElColorPicker`，见决策 D7）
```

## 5. 持久化与首屏防闪烁

- 存储：`@repo/utils` 的 `storage`（命名空间 + 类型安全 + JSON 序列化 + 过期），key 约定：
  - `fsd:theme`（`{ mode, primary }`）
  - `fsd:layout`（`{ mode, sidebarWidth, ... }`）
  - `fsd:lang`、`fsd:tabs`
- **FOUC 处理**：在 `main.ts` 最顶部先执行 `initTheme()`（读取 storage → 设置 `html.dark` 与 `--el-color-*`），再 `createApp().mount()`。
- SSR 不需要，故无需内联脚本；若后续加 SSR 再改为 `<head>` 内联片段。

## 6. 主题切换的 store 形态

```ts
// features/theme-switch/model/theme.store.ts
export const useThemeStore = defineStore('theme', () => {
  const mode = ref<'light' | 'dark' | 'auto'>(storage.get('fsd:theme')?.mode ?? 'light')
  const primary = ref<string>(storage.get('fsd:theme')?.primary ?? '#409EFF')
  const isDark = computed(() => resolveIsDark(mode.value))

  watchEffect(() => {
    applyDarkMode(mode.value)
    applyPrimaryColor(primary.value)
    persist()
  })

  return { mode, primary, isDark, setMode, setPrimary, resetTheme }
})
```

> 切换 `dark` 时无需刷新页面；切换品牌色同理（纯 CSS 变量写入）。

## 7. 布局模式

### 7.1 四种模式定义

| 模式      | 结构                                      | 适用场景             |
| --------- | ----------------------------------------- | -------------------- |
| `sidebar` | 左侧菜单（可折叠） + 顶部 Header + 内容区 | 通用后台             |
| `top`     | 顶部水平菜单 + 内容区                     | 一级菜单少的系统     |
| `mix`     | 顶部一级菜单 + 左侧二级菜单               | 模块多、层级深       |
| `dual`    | 左侧窄条主菜单 + 次级侧栏 + 内容区        | 平台型、模块切换频繁 |

### 7.2 组件结构

```
widgets/layout/
├─ AppLayout.vue        # 容器：<component :is="currentLayout" />，统一提供 Header/Tabs/Main 插槽
├─ SidebarLayout.vue
├─ TopLayout.vue
├─ MixLayout.vue
├─ DualLayout.vue
└─ ui/
   ├─ MenuTree.vue      # 递归菜单（唯一实现，四种模式复用）
   ├─ AppHeader.vue     # 面包屑/搜索/主题/布局/语言/用户下拉
   ├─ AppTabs.vue       # 多标签页
   ├─ AppLogo.vue
   └─ AppBreadcrumb.vue
```

```vue
<!-- AppLayout.vue 关键结构 -->
<script setup lang="ts">
const layout = useLayoutStore()
const MAP = { sidebar: SidebarLayout, top: TopLayout, mix: MixLayout, dual: DualLayout }
const current = computed(() => MAP[layout.mode])
</script>

<template>
  <component :is="current">
    <template #main>
      <router-view v-slot="{ Component, route }">
        <keep-alive :include="tabs.cachedViews">
          <component
            :is="Component"
            :key="route.meta.keepAlive ? String(route.name) : route.fullPath"
          />
        </keep-alive>
      </router-view>
    </template>
  </component>
</template>
```

### 7.3 切换机制

- `features/layout-switch/model/layout.store.ts` 持有 `mode`，持久化到 `fsd:layout`。
- 切换只换布局组件，**不重新注册路由、不刷新页面**；菜单树不变。
- `AppHeader` 提供切换入口（下拉 / 图标按钮），可放在「设置抽屉」中一并暴露。
- 响应式：`@vueuse/core` 的 `useBreakpoints`，小屏强制折叠侧边栏（抽屉式）。

### 7.4 布局配置（与主题正交）

| 项                | 默认         | 存储         |
| ----------------- | ------------ | ------------ |
| 侧边栏宽度 / 折叠 | 210px / 64px | `fsd:layout` |
| 顶栏高度          | 56px         | `fsd:layout` |
| 页面切换动画      | fade-slide   | `fsd:layout` |
| 面包屑显隐        | 显示         | `fsd:layout` |
| 水印              | 关闭         | `fsd:layout` |

> **P4 实现现状（2026-09-28）**：已落地「侧边栏宽度/折叠」（210 ↔ 64，`px` 常量在布局组件内）与「顶栏高度 56px」；
> `fsd:layout` 目前只持久化 `{ mode, collapsed }`。**页面切换动画 / 面包屑显隐 / 水印尚未实现**（不在 P4 任务清单内）：
> 若需要，建议 P8 质量收尾时按本表补齐（届时把 `LAYOUT_KEY` 的值扩为 `{ mode, collapsed, breadcrumb, watermark, ... }`，旧值读取按 D1 的回落策略兼容）。

## 8. 多标签页 Tabs + keep-alive

- `features/tabs/model/tabs.store.ts`：`visitedViews[]`、`cachedViews[]`、`addView / closeView / closeOthers / closeAll / refreshView / toggleAffix`。
- `cachedViews` 来自路由 `meta.keepAlive !== false` 且 `meta.keepAlive` 为 true 的 `route.name`。
- **刷新实现**：从 `cachedViews` 移除 → `nextTick` 后重新加入（配合 `router.replace` 或组件 `key` 时间戳）。
- 右键菜单：刷新 / 关闭 / 关闭其他 / 关闭左侧右侧 / 全部关闭；`meta.affix` 页签不可关闭。
- 上限策略：**已定 `MAX_CACHE = 20`**，超出按最近最少使用（LRU）淘汰；常量集中在 `features/tabs/model/constants.ts`（实施见 `docs/15` §3.2）。
- 缓存判定统一为 `keepAlive !== false`（默认缓存，与 DDL `keep_alive` 默认 1 一致）。
