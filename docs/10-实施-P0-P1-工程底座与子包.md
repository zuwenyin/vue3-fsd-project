### 1.2 `.npmrc`

```ini
registry=https://registry.npmjs.org/
```

> **pnpm 11 变更**：`.npmrc` **只**读取 `registry` 与鉴权相关设置。
> `strict-peer-dependencies` / `auto-install-peers` / `resolution-mode` 写在 `.npmrc` 会被**静默忽略**，必须改写到 `pnpm-workspace.yaml`（见 §1.1）：
>
> ```yaml
> strictPeerDependencies: false
> autoInstallPeers: true
> resolutionMode: highest
> ```
>
> （国内网络可将 `registry` 换成镜像源，如 `https://registry.npmmirror.com/`。）

> 构建脚本白名单同理：pnpm 11 **已移除** `onlyBuiltDependencies`，改为 `pnpm-workspace.yaml` 的 `allowBuilds`；根 `package.json` 的 `pnpm` 字段不再被读取（pnpm 会打印 `WARN ... pnpm field`），必须写在 `pnpm-workspace.yaml`：

```yaml
allowBuilds:
  esbuild: true
  '@parcel/watcher': true
  better-sqlite3: true
```

### 1.5 `eslint.config.js`

骨架见 `docs/06` §4，本阶段需**额外落地**三段：

1. **FSD 分层导入约束**（先启用两条，逐步加严）：

```js
{
  files: ['apps/web/src/shared/**/*.{ts,vue}'],
  rules: {
    'no-restricted-imports': ['error', {
      patterns: ['@/entities/*', '@/features/*', '@/widgets/*', '@/pages/*', '@/app/*'],
    }],
  },
},
{
  files: ['apps/web/src/entities/**/*.{ts,vue}'],
  rules: {
    'no-restricted-imports': ['error', {
      patterns: ['@/features/*', '@/widgets/*', '@/pages/*'],
    }],
  },
},
```

2. **Public API 约束**（禁止穿透到 slice 内部）：

```js
{
  files: ['apps/web/src/**/*.{ts,vue}'],
  rules: {
    'no-restricted-imports': ['error', {
      patterns: [
        { group: ['@/features/*/model/*', '@/features/*/ui/*', '@/features/*/lib/*'], message: '请从 slice 的 index.ts 导入' },
        { group: ['@/entities/*/model/*', '@/entities/*/lib/*'], message: '请从 slice 的 index.ts 导入' },
      ],
    }],
  },
}
```

> 注意：`no-restricted-imports` 在同一 `files` 分组内**只能声明一次**，上面两条 `patterns` 需合并到一个配置对象里（否则后面的覆盖前面的）。实施时按「一个分组一条规则」组织：shared 组、entities 组、通用组。

3. **server 覆盖**（Node 侧不需要 DOM/浏览器全局变量规则，且允许 `console`）：

```js
{
  files: ['apps/server/**/*.ts'],
  languageOptions: { globals: { ...globals.node } },
  rules: { 'no-console': 'off' },
}
```

### 1.10 CI（`.github/workflows/ci.yml`）

在 `docs/06` §11 基础上补充（**已定**，见 `docs/07` 决策 D6）：

- Node 版本矩阵只保留 `24.19.0`（与 `.nvmrc` 一致，避免原生模块 ABI 分裂）。
- **新增独立的 `server` job**（与 `web` 并行）：`type-check` + `vitest run`（`apps/server`，`supertest` 直接打 `createApp()`），**不设覆盖率门槛**。

```yaml
jobs:
  server:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
      - uses: pnpm/action-setup@v4
        with: { version: 11.9.0 }
      - uses: actions/setup-node@v5
        with: { node-version: 24.19.0, cache: 'pnpm' }
      - run: pnpm install --frozen-lockfile
      - run: pnpm --filter @repo/server run type-check
      - run: pnpm --filter @repo/server run test
```

> action 版本与 `docs/06` §11 保持一致（均为 `checkout@v5` / `setup-node@v5`）；`pnpm/action-setup` 必须带 `with: { version: 11.9.0 }`，否则会用 runner 自带 pnpm 而非 11.9.0。

> **CI 上的 SQLite 风险**：`better-sqlite3` 在 Linux runner 若无匹配 prebuild 会触发源码编译（需 `python3` + `build-essential`）。
> 处置顺序：① 先试 prebuild；② 失败则给 server job 设环境变量 `DB_DRIVER=node-sqlite` 走内置驱动（Node 24 已实测可用，见 `docs/11` §3.2）。
> **测试库统一用内存库**：`DB_PATH=:memory:`（`docs/11` §8.5），**不产生任何 `*.db` / `*.test.db` 文件**，所以 `.gitignore`（§1.11）只需覆盖开发库 `apps/server/data/*.db*`。

**对外 API 签名（已定型，实施阶段不得改名）**

```ts
// ---- storage（决策 D1：键统一 fsd: 前缀，禁止裸 localStorage）----
export interface StorageLike {
  get<T = unknown>(key: string, fallback?: T): T | undefined
  set(key: string, value: unknown, ttlMs?: number): void
  remove(key: string): void
  clear(): void // 只清本命名空间的键，不误伤第三方
}
export const storage: StorageLike // 默认后端 localStorage，前缀 'fsd'
export function createStorage(namespace: string, backend?: 'local' | 'session'): StorageLike
```

约定：

- 调用方一律写全键名 `storage.get('fsd:token')`；实现内部若发现已含 `fsd:` 前缀**不重复拼接**。
- `get` 遇到 JSON 解析失败 → 返回 `fallback` 并 `console.warn`，不抛异常。
- `set(key, value, ttlMs)` 带过期；读取时发现过期即删并返回 `fallback`。
- SSR / 无 `window` 环境降级为内存 Map（保证 `@repo/utils` 可在 Node 测试中直接使用）。

```ts
// ---- tree（菜单与路由共用）----
export interface ListToTreeOptions {
  idKey?: string // 默认 'id'
  parentKey?: string // 默认 'parentId'
  childrenKey?: string // 默认 'children'
}
export function listToTree<T>(list: T[], options?: ListToTreeOptions): Array<T & { children: T[] }>
export function treeMap<T, R>(
  tree: T[],
  fn: (node: T, depth: number) => R,
  childrenKey?: string,
): R[]
export function treeFilter<T>(tree: T[], predicate: (node: T) => boolean, childrenKey?: string): T[]
export function treeFind<T>(
  tree: T[],
  predicate: (node: T) => boolean,
  childrenKey?: string,
): T | undefined
export function flattenTree<T>(tree: T[], childrenKey?: string): T[]
export function sortByOrder<T extends { orderNo?: number }>(nodes: T[], childrenKey?: string): T[]
```

- `listToTree` 对**孤儿节点**（`parentId` 指向不存在的 id）按根节点处理，不丢数据；多根返回数组。
- `sortByOrder` 必须**稳定**（`orderNo` 相等保持输入顺序），菜单顺序依赖此性质。

`vite.config.ts` 见 `docs/05` §3：`external` 必须包含 `vue`、`element-plus`、`@element-plus/icons-vue`、`/^element-plus\/.*/`。

**Element Plus 引入纪律**（`docs/05` §3 + `docs/01` §7）：

- **只在 `@repo/ui` 内显式 import EP 组件**；`apps/web` 一律从 `@repo/ui` 取组件（`FsdTable` / `FsdForm` / `FsdDialog` / `FsdSelect` / `FsdTreeSelect` / `FsdTag` / `FsdSwitch` / `FsdButton` / `FsdIcon`）。
- **例外**：EP 的**非组件 API**（`ElMessage` / `ElMessageBox` / `ElLoading` / `ElNotification`）可在 `shared/` 与 `features/` 中直接 `import`，不算违反纪律。
- 若需要全量安装，由 `apps/web` 的 `app/providers/element.ts` 统一 `app.use(ElementPlus)` 或 `ElConfigProvider` 包裹（实施时二选一，倾向后者 + 局部引入）。

`FsdTable` 本阶段需支持的 props（菜单配置页强依赖）：

```ts
export interface FsdTableProps<T = any> {
  data: T[]
  columns?: FsdTableColumn[] // 可选：与 slot 二选一
  loading?: boolean
  rowKey?: string // 默认 'id'
  treeProps?: { children: string; hasChildren?: string }
  defaultExpandAll?: boolean
  pagination?: false | { page: number; pageSize: number; total: number }
  emptyText?: string
}
```

### 2.2.1 组件最小 props 契约

> 以下是**必须满足**的最小契约（菜单配置页与主题/Tabs 强依赖）。所有组件：`defineOptions({ name })` + props 类型从 `src/types/index.ts` 导出 + 在 `src/index.ts` 统一再导出。

```ts
// ---- FsdTable ----
export interface FsdTableColumn {
  key: string // 对应 row 的字段名
  label: string
  width?: number | string
  minWidth?: number | string
  align?: 'left' | 'center' | 'right'
  fixed?: 'left' | 'right'
  slot?: boolean // true → 走 #<key> 具名插槽（如 #title / #status / #actions）
  formatter?: (row: any) => string
}
// emits：'current-change'(row) | 'row-click'(row) | 'update:page'(page) | 'selection-change'(rows)
// expose：{ bodyRef } —— tbody 元素，供 vue-draggable-plus 的 useSortable 绑定（docs/14 §5.3）
// 树形：row-key + tree-props + default-expand-all 直接透传给 el-table；expand/collapse 通过 ref 暴露
//       toggleRowExpansion(row, expanded) 与 toggleExpandAll(expanded: boolean)

// ---- FsdForm / FsdFormItem ----
// FsdForm props：{ model: Record<string, unknown>; rules?: FormRules; labelWidth?: string;
//                  labelPosition?: 'left' | 'right' | 'top'; disabled?: boolean }
// FsdForm expose：validate(): Promise<boolean> | resetFields() | clearValidate()
// FsdFormItem props：{ label?: string; prop?: string; required?: boolean } + 默认插槽放控件

// ---- FsdSelect ----
export interface FsdOption {
  label: string
  value: string | number
  disabled?: boolean
}
// props：{ modelValue; options?: FsdOption[] | string[]; multiple?: boolean; filterable?: boolean;
//          allowCreate?: boolean; clearable?: boolean; placeholder?: string; disabled?: boolean }
// emits：'update:modelValue' | 'change'

// ---- FsdTreeSelect ----
// props：{ modelValue; data: Record<string, any>[]; props?: { value: string; label: string; children: string };
//          clearable?: boolean; filterable?: boolean; checkStrictly?: boolean; placeholder?: string }
// 默认映射 { value: 'id', label: 'title', children: 'children' }（菜单树直接可用）

// ---- FsdTag ----
// props：{ type?: 'primary' | 'success' | 'info' | 'warning' | 'danger';
//          size?: 'large' | 'default' | 'small'; effect?: 'dark' | 'light' | 'plain'; round?: boolean }

// ---- FsdSwitch ----
// props：{ modelValue: boolean; activeText?: string; inactiveText?: string; disabled?: boolean }
// emits：'update:modelValue' | 'change'

// ---- FsdButton ----
// props：{ type?: 'primary'|'success'|'warning'|'danger'|'info'|'default'; size?: 'large'|'default'|'small';
//          loading?: boolean; disabled?: boolean; icon?: string; text?: boolean; link?: boolean }
// emits：'click'

// ---- FsdIcon ----
// props：{ name?: string; size?: number | string; color?: string }
// 内部映射 @element-plus/icons-vue；未命中（空/不存在）渲染占位方块并 console.warn，不报错

// ---- FsdDialog ----
// props：{ modelValue: boolean; title?: string; width?: string | number;
//          appendToBody?: boolean; closeOnClickModal?: boolean; confirmText?: string; cancelText?: string;
//          confirmLoading?: boolean }
// emits：'update:modelValue' | 'confirm' | 'cancel' | 'closed'

// ---- FsdMenu / FsdSubMenu / FsdMenuItem（el-menu 系列再导出，供 widgets/layout 使用）----
// FsdMenu props：{ mode?: 'vertical' | 'horizontal'; defaultActive?: string; collapse?: boolean;
//                  uniqueOpened?: boolean; backgroundColor?: string; textColor?: string; activeTextColor?: string }
// FsdSubMenu props：{ index: string; popperClass?: string } + #title 插槽
// FsdMenuItem props：{ index: string; disabled?: boolean } emits：'click'
// 颜色一律走 `var(--fsd-*)`，不接受硬编码（Stylelint 会拦截）

// ---- FsdColorPicker ----
// props：{ modelValue: string; predefine?: string[]; showAlpha?: boolean; size?: 'large'|'default'|'small' }
// emits：'update:modelValue' | 'change' | 'active-change'
```

`packages/ui` 的单测范围（`docs/06` §8）：每个组件至少一条「渲染 + 关键事件」用例；`FsdTable` 需覆盖树形渲染与 `#<key>` 插槽；`FsdIcon` 需覆盖未命中降级。

## 5. 风险与回退

| 风险                                          | 现象                         | 回退方案                                                                                         |
| --------------------------------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------ |
| catalog 与包内版本冲突                        | install 报 `catalog:` 未定义 | 确认该依赖已写入 `pnpm-workspace.yaml` 的 `catalog`；临时可写死版本后补 catalog                  |
| `vite-plugin-dts` 对 `.vue` 声明异常          | `dist/index.d.ts` 缺组件类型 | 兜底：`vue-tsc -p tsconfig.build.json --declaration --emitDeclarationOnly --outDir dist`         |
| Stylelint 规则名失效                          | 启动报 `Unknown rule`        | 删失效规则（优先保留令牌强制组）；`--print-config` 先行验证                                      |
| husky 未生效                                  | 提交不触发                   | 确认根 `prepare: husky` 已执行；`.husky/_` 目录存在                                              |
| Windows 换行导致 lint 失败                    | CRLF 报 `end_of_line`        | `.gitattributes` 加 `* text=auto eol=lf`                                                         |
| CI 上 `better-sqlite3` 编译失败（server job） | 安装或测试阶段报错           | ① 优先用 prebuild；② 失败则给 server job 设 `DB_DRIVER=node-sqlite` 走内置驱动（`docs/11` §3.2） |
| `FsdTable` 的 `bodyRef` 在树形数据刷新后失效  | 拖拽无反应                   | 数据更新后 `nextTick` 重新取 `bodyRef`；必要时 `FsdTable` 暴露 `refreshSortable()`               |
